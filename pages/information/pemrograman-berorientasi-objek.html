Pemrograman Berorientasi Objek (OOP)

OOP adalah cara memprogram dengan membuat “objek” yang menyerupai benda di dunia nyata agar kode lebih rapi dan mudah dipakai ulang.


Pengertian OOP

Object Oriented Programming (OOP) atau Pemrograman Berorientasi Objek adalah paradigma pemrograman yang memodelkan masalah menggunakan objek (instance) dari kelas.

  • Objek memiliki data (atribut/properti).
  • Objek memiliki perilaku (method/fungsi).
  • Kode menjadi lebih terstruktur dan mudah diperluas.

Konsep Penting OOP

  • Kelas: cetakan untuk membuat objek (contoh: class Siswa).
  • Objek: hasil instansiasi kelas (contoh: siswa1).
  • Encapsulation (Pembungkusan): melindungi data agar hanya bisa diakses melalui method.
  • Inheritance (Pewarisan): satu kelas menurunkan kelas lain (misal: Admin turunan dari Pengguna).
  • Polymorphism (Polimorfisme): method yang sama bisa berperilaku berbeda pada objek berbeda.

Contoh OOP + Objek (JavaScript)

Contoh sederhana membuat kelas Siswa lalu membuat objeknya dan memanggil method:

class Siswa {
  constructor(nama, nis) {
    this.nama = nama; // atribut/properti
    this.nis = nis;
  }

  info() {
    return `Nama: ${this.nama}, NIS: ${this.nis}`; // method/perilaku
  }
}

// Membuat objek (instansiasi)
const siswa1 = new Siswa('Gilang', '12345');
const siswa2 = new Siswa('Rina', '67890');

console.log(siswa1.info());
console.log(siswa2.info());
  • Kelas: Siswa
  • Objek: siswa1 dan siswa2
  • Atribut: nama, nis
  • Method: info()

Contoh Relevan dengan RPL

Saat membuat aplikasi sekolah (misal: absensi, nilai, profil siswa), OOP membantu memisahkan data dan fitur. Contohnya: objek Siswa punya atribut nilai, sedangkan method dapat menghitung rata-rata atau menampilkan rapor.
