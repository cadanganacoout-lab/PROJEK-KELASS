Jaringan Komputer

Materi dasar tentang bagaimana komputer saling terhubung untuk berbagi data dan layanan.

Pengertian

Jaringan komputer adalah hubungan antar perangkat (komputer, HP, server, router) agar bisa berbagi data dan berbagi sumber daya (misalnya printer, internet, file).

  • Memungkinkan komunikasi antar perangkat.
  • Mempermudah pertukaran informasi.
  • Menjadi dasar internet dan intranet.

Komponen Jaringan

  • PC/Client: perangkat pengguna.
  • Server: menyediakan layanan (misal database, website).
  • Router: mengarahkan paket data antar jaringan.
  • Switch: menghubungkan banyak perangkat di LAN.
  • Media transmisi: kabel (UTP/fiber) atau nirkabel (Wi-Fi).

Jenis Jaringan

  • LAN (Local Area Network): jaringan di kantor/sekolah (ruang/gedung).
  • MAN (Metropolitan Area Network): mencakup kota.
  • WAN (Wide Area Network): mencakup antar kota/negara.

Contoh Kasus Nyata

Contoh di sekolah:

  • Kelas memiliki Wi-Fi/LAN untuk akses materi.
  • Guru mengunggah soal/absensi ke server sekolah (atau Google Drive/hosting).
  • Siswa dapat mengakses melalui browser dan menampilkan data dari server.

Alur sederhana: siswa meminta data → server memproses → data dikirim kembali → browser menampilkan.

Contoh Proses Komunikasi (Singkat)

Saat kamu membuka halaman website, browser melakukan request (menghubungi server). Server mengirim respons (data halaman). Lalu browser menampilkan tampilan.

  • Request: browser minta halaman.
  • Response: server mengirim HTML/CSS/JS.
  • Rendering: browser merangkai menjadi tampilan.
