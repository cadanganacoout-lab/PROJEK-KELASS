Pemrograman Web

Materi dasar membuat website/aplikasi berbasis browser: dari konsep hingga contoh sederhana.


Pengertian

Pemrograman Web adalah proses membuat aplikasi yang berjalan di browser (seperti Chrome/Firefox) menggunakan bahasa pemrograman. Umumnya melibatkan HTML, CSS, dan JavaScript, serta bisa juga menggunakan server-side (misal PHP/Node.js).

  • HTML: struktur halaman.
  • CSS: tampilan/warna/layout.
  • JavaScript: interaksi dan logika.

Contoh Penerapan (Website Sederhana)

Contoh: membuat tombol yang saat diklik akan menampilkan pesan.
  • HTML menyediakan tombol dan elemen output.
  • JavaScript menangani event klik.
  • Hasil langsung berubah di halaman.

Front-End vs Back-End (Singkat)

  • Front-End : bagian yang dilihat pengguna (UI/UX).
  • Back-End : bagian server yang mengolah data (misal login, database, API).
  • Web modern sering memakai API untuk pertukaran data.

Contoh Kasus Nyata untuk Sekolah

Misal web sekolah menampilkan profil kelas, daftar guru, galeri, dan video. Komponen web bisa dibagi: halaman HTML (konten), CSS (desain), dan JS (misal fitur jam/hari berjalan, animasi, atau filter galeri).
